# 官報破産関連公告検索スクリプト

官報PDFから破産関連公告をOCRで読み取り、指定した裁判所や氏名で検索するPythonスクリプトです。

官報PDFをページ単位で処理し、段組みを分割して日本語OCRを実行します。抽出した公告をテキストファイル（TXT）に出力します。

## 主な機能

-   官報PDFから破産関連公告を検索
-   Tesseract-OCRまたはNDL OCR-Liteを選択して日本語OCRを実行
-   段組数をINIファイルで指定
-   裁判所名をINIファイルで指定
-   裁判所名の指定にワイルドカード `*` と `?` を使用可能
-   複数の裁判所や公告名を指定可能
-   複数の入力PDFをまとめて指定し、順番に処理可能
-   `-n` オプションで氏名による絞り込みが可能
-   検索結果を入力PDFと同じフォルダーにTXT形式で出力
-   OCRの中間データ出力を設定可能
-   INIファイルを指定して検索条件を変更可能

## 動作環境

-   Windows
-   Python 3.8以降を想定
-   PyMuPDF
-   ini_cfg_parser
-   Tesseract-OCR（Tesseractを使用する場合）
-   Tesseract-OCRの日本語言語データ `jpn`（Tesseractを使用する場合）
-   NDL OCR-Lite（NDL OCR-Liteを使用する場合）
-   [uv](https://github.com/astral-sh/uv)（NDL
    OCR-Liteをuvで導入する場合）

## ファイル構成

``` text
kanpo-bankruptcy-search/
├── kanpo_search.py
├── kanpo_search.ini
└── README.md
```

`kanpo_search.py` は検索スクリプトです。

`kanpo_search.ini`
は検索条件やOCRの設定ファイルです。スクリプト実行時にINIファイルが存在しない場合は、既定の設定で作成されます。`-c`
オプションで指定したINIファイルが存在しない場合はエラーになります。

## インストール

### 1. Pythonパッケージのインストール

コマンドプロンプトで、次のコマンドを実行します。

``` cmd
python -m pip install pymupdf ini_cfg_parser
```

### 2. OCRエンジンを選択して導入

このスクリプトでは、INIファイルの `[OCR]` セクションにある `ocr`
の設定で、使用するOCRエンジンを切り替えられます。

| `ocr` の設定値 | 使用するOCRエンジン | 事前準備 |
| :--- | :--- | :--- |
| `tesseract` | Tesseract-OCR | Tesseract-OCR本体と日本語言語データ `jpn` をインストール |
| `ndlocr-lite` | NDL OCR-Lite | NDL OCR-Liteをインストールし、`ndlocr-lite` コマンドを実行できる状態にする |


#### A. Tesseract-OCRを使用する場合

Tesseract-OCRをインストールしてください。

Windowsで標準的なインストール先を使用している場合、実行ファイルは次の場所にあります。

``` text
C:\Program Files\Tesseract-OCR\tesseract.exe
```

スクリプトは、INIファイルで指定された実行ファイル、PATH上の実行ファイル、または標準的なWindowsのインストール先からTesseract-OCRを検索します。

必要に応じて、`kanpo_search.ini` の `[OCR]`
セクションに実行ファイルのフルパスを設定してください。

コマンドプロンプトで、次のコマンドを実行して日本語言語データが利用可能か確認できます。

``` cmd
"C:\Program Files\Tesseract-OCR\tesseract.exe" --list-langs
```

日本語OCRを使用するには、一覧に `jpn` が含まれている必要があります。

確認例：

``` text
eng
jpn
osd
```

INIファイルでは、次のように指定します。

``` ini
[OCR]
ocr=tesseract
実行ファイル=
言語=jpn
PSM=6
```

#### B. NDL OCR-Liteを使用する場合（uvを使用）

[uv](https://github.com/astral-sh/uv)
を使用できる環境では、次の手順でNDL
OCR-Liteを導入できます。導入後は、`ndlocr-lite`
コマンドから実行できます。

まず、NDL
OCR-Liteのリポジトリを取得し、uvでツールとしてインストールします。

``` bash
git clone https://github.com/ndl-lab/ndlocr-lite
cd ndlocr-lite
uv tool install .
```

インストール後、`ndlocr-lite`
コマンドを実行できることを確認してください。コマンドが見つからない場合は、uvのツール実行ファイルの保存先がPATHに含まれているか確認してください。

INIファイルでは、次のように指定します。

``` ini
[OCR]
ocr=ndlocr-lite
```

NDL OCR-Liteを使用する場合、Tesseract-OCRの
`実行ファイル`、`言語`、`PSM` の設定はTesseract用の設定です。

### 3. INIファイルの設定

`kanpo_search.ini` の `[OCR]`
セクションで、使用するOCRエンジンを指定してください。

設定例（Tesseract-OCR）：

``` ini
[OCR]
ocr=tesseract
実行ファイル=
言語=jpn
PSM=6
解像度=300
中間データ出力=0
```

設定例（NDL OCR-Lite）：

``` ini
[OCR]
ocr=ndlocr-lite
実行ファイル=
言語=jpn
PSM=6
解像度=300
中間データ出力=0
```

`ocr` の値は `tesseract` または `ndlocr-lite`
を指定します。使用するOCRエンジンがインストールされ、コマンドから実行できる状態であることを確認してください。

## 設定ファイル

`kanpo_search.ini`
では、検索対象の裁判所、段組数、公告名、OCRの設定、出力文字コードなどを指定します。

設定ファイルの例：

``` ini
; 官報検索設定
; 日本語UTF-8で保存してください。

[官報]
; 裁判所はワイルドカード * と ? に対応
; 複数指定する場合はカンマ区切り
裁判所=*地方裁判所*

; 今回の官報は4段組
段組数=4

; OCRで抽出対象にする公告名
; 複数指定する場合はカンマ区切り
公告=破産手続開始,破産手続開始及び免責許可申立てに関する意見申述期間

[OCR]
; OCRエンジン：tesseract または ndlocr-lite
ocr=ndlocr-lite

; OCRの実行ファイル。空欄なら自動検索
実行ファイル=

; Tesseract-OCRで使用する言語
言語=jpn

; Tesseract Page Segmentation Mode
PSM=6

; PDFを画像化する解像度
解像度=300

; 中間データを出力する場合は1、出力しない場合は0
中間データ出力=0

[出力]
文字コード=utf-8
```

### \[官報\] セクション

  ------------------------------------------------------------------------------------------------------------
  設定項目                            説明
  ----------------------------------- ------------------------------------------------------------------------
  裁判所                              検索対象の裁判所名。`*` と `?`
                                      のワイルドカードに対応します。複数指定する場合はカンマ区切りです。

  段組数                              PDFの段組数を指定します。上記の例では4段組です。

  公告                                抽出対象とする公告名を指定します。複数指定する場合はカンマ区切りです。
  ------------------------------------------------------------------------------------------------------------

### \[OCR\] セクション

  --------------------------------------------------------------------------------------------------------
  設定項目                            説明
  ----------------------------------- --------------------------------------------------------------------
  ocr                                 使用するOCRエンジン。`tesseract` または `ndlocr-lite` を指定します。

  実行ファイル                        Tesseract-OCRの実行ファイルのパス。空欄の場合は自動検索します。NDL
                                      OCR-Liteを使用する場合はTesseract用の設定です。

  言語                                Tesseract-OCRで使用する言語データ。日本語の場合は `jpn` です。NDL
                                      OCR-LiteではTesseract用の設定です。

  PSM                                 Tesseract-OCRのページ分割モードです。NDL
                                      OCR-LiteではTesseract用の設定です。

  解像度                              PDFを画像化する際の解像度（DPI）です。

  中間データ出力                      `0` は中間データを出力しない設定、`1` は出力する設定です。
  --------------------------------------------------------------------------------------------------------

### \[出力\] セクション

  -------------------------------------------------------------------------------
  設定項目                            説明
  ----------------------------------- -------------------------------------------
  文字コード                          出力TXTファイルの文字コードです。既定値は
                                      `utf-8` です。

  -------------------------------------------------------------------------------

## 実行方法

### 1. 基本的な実行

コマンドプロンプトで、スクリプトと入力PDFのパスを指定して実行します。

``` cmd
python kanpo_search.py "C:\官報\官報PDF.pdf"
```

入力PDFのパスは、実際に検索したいPDFのパスに置き換えてください。

複数のPDFを処理する場合は、入力ファイルのパスをスペース区切りで複数指定します。パスに空白や日本語が含まれる場合は、それぞれをダブルクォーテーションで囲んでください。

``` cmd
python kanpo_search.py "C:\官報\官報PDF_1.pdf" "C:\官報\官報PDF_2.pdf" "C:\官報\官報PDF_3.pdf"
```

指定したPDFは、コマンドに記載した順番に処理されます。各PDFの検索結果は、それぞれの入力PDFと同じフォルダーに出力されます。

### 2. 氏名を指定して検索

`-n` または `--name`
オプションで氏名を指定できます。指定した場合は、裁判所の条件に加えて氏名でも絞り込みます。

``` cmd
python kanpo_search.py "C:\官報\官報PDF.pdf" -n "山田太郎"
```

氏名は検索対象の文字列に一致するかどうかで判定されます。OCRの読み取り誤りがある場合は、該当する公告が抽出されないことがあります。

### 3. 使用するINIファイルを指定

`-c` または `--config` オプションでINIファイルを指定できます。

``` cmd
python kanpo_search.py "C:\官報\官報PDF.pdf" -c "C:\設定\kanpo_search.ini"
```

指定したINIファイルが存在しない場合はエラーになります。

### 4. ヘルプの表示

``` cmd
python kanpo_search.py --help
```

バージョンを確認するには、次のコマンドを実行します。

``` cmd
python kanpo_search.py --version
```

## 検索結果

検索結果は、入力PDFと同じフォルダーに、入力PDFのファイル名に解像度（DPI）を付加した
`.txt` ファイルとして出力されます。

検索結果には、入力PDFのパス、指定した裁判所、氏名の指定内容、該当件数、該当した公告のページ番号・段番号、抽出された裁判所名、OCRで読み取った公告のテキストが含まれます。

該当件数が0件の場合でも、検索結果ファイルは出力されます。

## 中間データ出力

INIファイルの `[OCR]` セクションにある `中間データ出力`
で、中間データの出力を切り替えます。

``` ini
中間データ出力=0
```

中間データを出力しない設定です。

``` ini
中間データ出力=1
```

中間データを出力する設定です。OCR結果の確認や検索条件の調整時に利用できます。中間OCRテキストは、入力PDFと同じフォルダーに、PDF名と解像度（DPI）を付けた
`{PDF名}_{DPI}dpi_ocr.txt`
の形式で出力されます。検索結果ファイルも解像度（DPI）を付けたファイル名で出力されます。

## 注意事項

-   OCRの結果は、PDFの画質や文字の状態によって変わります。
-   文字がかすれている場合や、段組みの境界が不明瞭な場合は、公告名や裁判所名を正しく認識できないことがあります。
-   該当公告が見つからない場合でも、OCRの読み取り誤りが原因となっている可能性があります。
-   氏名で検索する場合は、旧字体、異体字、OCRによる誤認識などに注意してください。
-   検索結果は確認用の資料です。重要な判断を行う場合は、元の官報PDFと照合してください。
-   官報PDFの段組数に合わせて、INIファイルの `段組数`
    を設定してください。
-   細かい文字や数字で文字化けが発生することがあります。処理時間と文字化けの影響度合いに応じて、INIファイルの
    `[OCR]` セクションで `解像度` の値を調整してください。
