# 官報破産関連公告検索スクリプト

## 概要

官報PDFをTesseract-OCRで文字認識し、破産関連公告を検索するPythonスクリプトです。

指定した裁判所、公告の種類、氏名を条件として検索し、該当する公告のテキストを抽出して、入力PDFと同じフォルダにTXTファイルとして出力します。

官報PDFの検索・確認作業を効率化することを目的としています。

## 主な機能

- 官報PDFをページごとに画像化し、OCRで文字認識
- PDFを指定した段組数に分割して検索
- 裁判所名をワイルドカードで指定
- 複数の破産関連公告を検索対象として指定
- 氏名を指定して検索結果を絞り込み
- 検索条件をINIファイルで管理
- INIファイルが存在しない場合、デフォルト設定で自動生成
- 検索結果をTXTファイルに出力
- `-v` / `--version` でバージョン表示
- `-h` / `--help` でヘルプ表示
- PyInstallerでEXE化した場合にも実行できるように対応

## 動作環境

- Windows
- Python 3.8以降を想定
- PyMuPDF
- ini_cfg_parser
- Tesseract-OCR
- Tesseract-OCRの日本語学習データ

※ 実際の動作環境は、使用するPython、ライブラリ、Tesseract-OCRのバージョンによって異なる場合があります。

## 必要なライブラリのインストール

### 1. Python

Pythonがインストールされていない場合は、公式サイトからインストールしてください。

https://www.python.org/downloads/

Windowsのコマンドプロンプトで、Pythonのバージョンを確認します。

```cmd
python --version
```

### 2. PyMuPDF

PDFの読み込み、ページの画像化などに使用します。

```cmd
python -m pip install pymupdf
```

Pythonスクリプトでは、次のようにインポートします。

```python
import fitz  # PyMuPDF
```

### 3. ini_cfg_parser

INIファイルから検索条件などの設定値を読み込むために使用します。

```cmd
python -m pip install ini_cfg_parser
```

Pythonスクリプトでは、次のようにインポートします。

```python
import ini_cfg_parser as ini
```

### 4. ライブラリのインストール確認

```cmd
python -m pip show pymupdf
python -m pip show ini_cfg_parser
```

インストールされていない場合は、上記のインストールコマンドを実行してください。

## Tesseract-OCRのインストール

Tesseract-OCRは、PDFを画像化したものから文字を認識するために必要です。

Pythonのライブラリとは別に、Tesseract-OCR本体をインストールしてください。

### 1. Windows版Tesseract-OCR

Windows向けのインストーラーについては、次の配布元を参照してください。

https://github.com/UB-Mannheim/tesseract/wiki

インストール時には、日本語の文字認識に必要な日本語学習データ（Japanese / jpn）が利用できることを確認してください。

### 2. インストール確認

インストール後、コマンドプロンプトで次のコマンドを実行します。

```cmd
tesseract --version
```

日本語学習データが利用可能か確認する場合は、次のコマンドを実行します。

```cmd
tesseract --list-langs
```

一覧に `jpn` が含まれていることを確認してください。

### 3. Tesseract-OCRが見つからない場合

スクリプトは、次の順番でTesseract-OCRの実行ファイルを検索します。

1. INIファイルの `[OCR] 実行ファイル` に指定されたパス
2. 環境変数PATHから検索した `tesseract`
3. `C:\Program Files\Tesseract-OCR\tesseract.exe`
4. `C:\Program Files (x86)\Tesseract-OCR\tesseract.exe`

上記で見つからない場合は、`kanpo_search.ini` の `[OCR]` セクションにある `実行ファイル` に、Tesseract-OCRの実行ファイルのフルパスを指定してください。

例：

```ini
[OCR]
実行ファイル = C:\Program Files\Tesseract-OCR\tesseract.exe
言語 = jpn
PSM = 6
解像度 = 300
```

※ パスは実際のインストール先に合わせて変更してください。

## 使用方法

### 1. ファイルの配置

スクリプトと設定ファイルを、例えば次のように配置します。

```text
kanpo_search/
├─ kanpo_search.py
├─ kanpo_search.ini
└─ 官報PDFファイル.pdf
```

※ スクリプト名は実際のファイル名に合わせてください。

### 2. 基本的な実行

コマンドプロンプトでスクリプトのあるフォルダに移動し、次のように実行します。

```cmd
python kanpo_search.py "官報PDFファイル.pdf"
```

検索結果は、入力PDFと同じフォルダに、同じファイル名の拡張子を `.txt` に変更したファイルとして出力されます。

例：

```text
官報PDFファイル.pdf
官報PDFファイル.txt
```

### 3. 氏名を指定して検索

氏名を指定すると、設定された裁判所と氏名の両方に一致する箇所を検索します。

```cmd
python kanpo_search.py "官報PDFファイル.pdf" -n "山田太郎"
```

氏名を指定しない場合は、氏名による絞り込みを行いません。

### 4. INIファイルを指定して実行

別のINIファイルを使用する場合は、`-c` または `--config` を指定します。

```cmd
python kanpo_search.py "官報PDFファイル.pdf" -c "kanpo_search.ini"
```

氏名とINIファイルを同時に指定することもできます。

```cmd
python kanpo_search.py "官報PDFファイル.pdf" -n "山田太郎" -c "kanpo_search.ini"
```

### 5. ヘルプとバージョン

ヘルプを表示します。

```cmd
python kanpo_search.py -h
```

バージョンを表示します。

```cmd
python kanpo_search.py -v
```

## 設定ファイル（kanpo_search.ini）

検索条件やOCRの設定は、INIファイルで変更できます。

スクリプトと同じ場所にINIファイルが存在しない場合、スクリプトはデフォルト値でINIファイルを自動生成します。

### [官報] セクション

| 設定項目 | デフォルト値 | 説明 |
|---|---|---|
| 裁判所 | `*地方裁判所*` | 検索対象の裁判所名。ワイルドカード `*`、`?` を使用可能 |
| 段組数 | `4` | PDFページを分割する段組数 |
| 公告 | `破産手続開始` | 検索対象とする公告名。複数指定可能 |

裁判所名は、例えば次のように指定できます。

```ini
[官報]
裁判所 = *地方裁判所*
段組数 = 4
公告 = 破産手続開始
```

公告はカンマ区切りで複数指定できます。

```ini
公告 = 破産手続開始,破産手続終結,免責許可決定
```

複数の公告を指定した場合、いずれかの公告名が認識テキストに含まれる箇所が検索対象になります。

### [OCR] セクション

| 設定項目 | デフォルト値 | 説明 |
|---|---|---|
| 実行ファイル | 空欄 | Tesseract-OCRの実行ファイルのパス |
| 言語 | `jpn` | OCRで使用する言語 |
| PSM | `6` | Tesseract-OCRのページ分割・認識モード |
| 解像度 | `300` | PDFを画像化する際の解像度（DPI） |

```ini
[OCR]
実行ファイル =
言語 = jpn
PSM = 6
解像度 = 300
```

解像度を上げると文字認識の精度が改善する場合がありますが、処理時間やメモリ使用量も増加します。

### [出力] セクション

| 設定項目 | デフォルト値 | 説明 |
|---|---|---|
| 文字コード | `utf-8` | 出力TXTファイルの文字コード |

```ini
[出力]
文字コード = utf-8
```

## 検索対象となる公告

初期設定では「破産手続開始」を検索します。

設定ファイルの `[官報]` セクションに、次のような公告名を指定できます。

- 破産手続開始
- 破産手続開始及び免責許可申立てに関する意見申述期間
- 破産手続終結
- 破産手続終結及び免責許可決定
- 破産債権の届出期間及び一般調査期日
- 破産手続開始及び破産手続廃止
- 破産手続開始・破産手続廃止及び免責許可申立てに関する意見申述期間
- 破産手続廃止及び免責許可決定
- 免責許可決定
- 免責決定確定
- 免責決定及び免責決定確定
- 破産債権の届出期間及び一般調査期間

※ 上記は設定例です。官報に掲載されるすべての公告名を網羅するものではありません。必要に応じて検索対象を追加・変更してください。

## 出力内容

出力TXTファイルには、次の情報が記録されます。

- 入力PDFのパス
- 検索条件として指定した裁判所
- 氏名の指定内容
- 該当件数
- 該当箇所のページ番号
- 該当箇所の段番号
- 認識された裁判所名
- OCRで認識したテキスト

該当箇所は、ページ番号と段番号を確認できる形式で出力されます。

## 注意事項

- OCRによる文字認識のため、誤認識や文字の欠落が発生することがあります。
- OCR結果に公告名や裁判所名が正しく認識されない場合、検索結果から漏れる可能性があります。
- 氏名の検索は、OCRで認識された文字列に対する部分一致です。異体字や誤認識がある場合、該当箇所が見つからないことがあります。
- 段組数はPDFのレイアウトに合わせて設定してください。初期値は4段です。
- 本スクリプトは、検索対象の公告を必ずすべて抽出できることを保証するものではありません。
- 重要な確認や手続きに使用する場合は、必ず元の官報PDFを開いて内容を確認してください。
- 官報PDFの取得元や利用条件については、提供元の規約等を確認してください。
